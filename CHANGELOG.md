# Changelog

## Alpha 1.46

- Світ, прогрес героя й позиція записуються разом. Якщо поточне збереження пошкоджене, гра пробує попереднє повне збереження.
- Автозбереження працює кожні дві хвилини гри, після повного відпочинку й при виході в меню.
- Windows-збірка зберігає прогрес у папці даних користувача та імпортує старі збереження з папки гри, залишаючи оригінали.
- Монстри, галюцинації та тіні блоків тимчасово вимкнені. F6–F8 доступні в Unity Editor і Windows Development.
- У меню Unity **Broken Heart → Build** доступні Development і Release збірки для Windows.
